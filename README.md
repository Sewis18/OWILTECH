## Cómo publicarla en GitHub Pages
1. Crea un repositorio nuevo en GitHub llamado `owiltech`
2. Sube TODOS los archivos de este ZIP (index.html, owiltech-logo.png, favicon.ico, favicon.png)
   IMPORTANTE: Sube todos juntos en la raíz, no en carpetas, para que el favicon funcione.
3. Ve a Settings > Pages
4. En Branch elige `main` y carpeta `/ (root)` y dale Save
5. Tu link quedará: https://TUUSUARIO.github.io/owiltech/
6. Abre el link en Chrome y verás tu logo de Owiltech en la pestaña del navegador (al lado del título).
